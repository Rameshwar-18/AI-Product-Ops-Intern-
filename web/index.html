03 / Autonomous Pipeline

The Research Agent Architecture

How raw discovery transforms into rigorously verified agent tooling intelligence.

STAGE 01
Pass 1: Baseline
Initial high-velocity pass using LLM parametric knowledge combined with single targeted search queries. Generates early baseline estimates and initial schema mapping.
STAGE 02
Pass 2: Deep Scrape
Firecrawl crawls official developer documentation portals, API references, authentication specs, and pricing matrices. Quoted text snippets and direct documentation URLs required for every field.
STAGE 03
Pass 3: Verifier Loop
Independent verifier agent audits claims strictly against fetched page text. Flags unsupported claims as unknown, enforces official vendor-owned MCP rules, and routes unverified claims to human review.
STAGE 04
Human Flagging
Deterministic routing of ambiguous access barriers (login walls, partner questionnaires, contact-sales NDA portals) into a dedicated audit queue.

Analysis of Agent Limitations & Extraction Failures

Direct post-mortem of verified discrepancies between automated agent extraction and human ground truth.

1. Stale Documentation & Deprecated Rules (Amazon SP-API)

Evidenced: In Pass 1, the agent cited AWS Signature Version 4 (SigV4) as a blocker for Amazon SP-API. Human ground truth confirms Amazon officially deprecated mandatory SigV4 on October 2, 2023 in favor of LWA OAuth 2.0 tokens. In Pass 3, the verifier encountered a scraper block on the portal and wiped auth to unknown.
[Hypothesis] The agent's initial parametric retrieval drew from pre-October 2023 tutorials or outdated documentation mirrors.

2. Missing Official MCP Discovery (Otter AI, GitHub)

Evidenced: Across all three passes, the agent reported mcp_server_exists: false for both Otter AI and GitHub. Ground truth verification confirmed official vendor MCP endpoints exist for both (mcp.otter.ai via marketplace connectors and api.githubcopilot.com/mcp/ via official Copilot MCP).
[Hypothesis] Automated MCP web search targeted root developer landing pages rather than vendor integration directories or Copilot subdomains.

3. Scraping the Wrong Documentation Source (NotebookLM)

Evidenced: The agent logged ai.google.dev/gemini-api/docs as its source and concluded NotebookLM has no developer API (verdict: unknown). Ground truth confirms NotebookLM Enterprise is officially documented under Google Cloud Discovery Engine (docs.cloud.google.com/.../api-notebooks) using Cloud IAM Bearer tokens.
[Hypothesis] Broad search queries anchored on the consumer Google AI Studio portal rather than the Google Cloud enterprise docs.

4. Verifier Pass 3 Over-Pruning (Twilio Accuracy Drop)

Evidenced: In Pass 1 and Pass 2, the agent correctly identified Twilio's authentication methods as ['API key', 'OAuth2', 'Basic'] (matching ground truth Basic; OAuth2). In Pass 3, the verifier strictly wiped this to unknown with the log: "The fetched text does not explicitly mention the authentication methods". This single over-pruning action directly caused evaluated overall sample accuracy to drop from 41.7% to 33.3%.

05 / Honest Assessment

Limitations & Apps That Defeated the Agent

Honest documentation of boundary conditions, API barriers, and edge cases.

Otter AI (Official MCP Sourced; Enterprise REST)

Sourced (Ground Truth Checklist): Official MCP server exists at mcp.otter.ai (evidenced via Anthropic connector at claude.com/marketplace/connectors/otter-ai and OpenAI business plugins). REST API keys require an Enterprise workspace tier (evidenced via cotlet.dev/integrations/otter-api-mcp-server).
Unverified claims: Consumer marketing pages omit programmatic documentation, causing automated scrapers to initially conclude no API existed.

Amazon SP-API (SigV4 Deprecation Sourced; Seller Access)

Sourced (Ground Truth Checklist): AWS Signature Version 4 (SigV4) request signing was officially deprecated by Amazon on October 2, 2023 in favor of standard LWA OAuth 2.0 exchange tokens (evidenced via official changelog at developer-docs.amazon.com/sp-api/v2.0/changelog/sp-api-will-no-longer-require-aws-iam-or-aws-signature-version-4).
Unverified claims: Access tier and sandbox endpoints remain unverified without a verified Professional Seller account and completed data protection assessment.

PitchBook (Institutional Gating Sourced; Pricing Unverified)

Sourced (Record): Direct REST API endpoints are documented at pitchbook.com/news/pitchbook-api, but access is strictly gated behind enterprise sales agreements and institutional procurement.
Unverified claims: Pricing is not public as PitchBook does not publish tier or API pricing on its website.

fanbasis (Consumer Platform Sourced; API Unverified)

Sourced (Record): Scraped domain (fanbasis.com) indicates a consumer celebrity and creator engagement platform. No public developer documentation, endpoint references, or API keys were retrieved.
Unverified claims: Developer API availability is unverified without direct corporate sales outreach.

iPayX (Institutional Utility Gateway; Endpoints Unverified)

Sourced (Record): Scraped portal (ipayx.com) represents an institutional utility bill payment processing service. Documentation details and authentication specs are gated behind client onboarding forms.
Unverified claims: Self-serve developer sandbox, REST endpoints, and public API keys are unverified without commercial onboarding.

Official MCP Undercount (Pumble & Ecwid)

Verifier notes state official MCP servers exist for Pumble and Ecwid, but the stored mcp_server_exists value is false — a pipeline inconsistency, so the 5% count is an undercount.

Sherlock & Mermaid CLI (Local CLI Utilities)

Sourced (Records): Open-source command-line utilities rather than hosted HTTP microservices. Composio must execute these via local container sandboxes or Node/Python subprocesses rather than remote HTTP requests.

Bot Blocking & Login Walls

Sourced (Pipeline Logs): Platforms utilizing Cloudflare anti-bot verification, single-page app (SPA) documentation rendering, or mandatory workspace logins before revealing credentials prevent static scraper retrieval, routing to human review.
